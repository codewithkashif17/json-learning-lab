# JSON Learning Lab

A hands-on Node.js learning project focused on understanding JSON data, file handling, CLI input, and menu-driven applications.

The project is organized into small daily tasks so that each concept can be learned and practiced step by step.

```
📁 Project Structure
json-learning-lab/
│
├── package.json
├── README.md
│
├── docs/
│   └── day-03-cli-menu.md
│
└── src/
    ├── index.js
    │
    ├── data/
    │   ├── menu.json
    │   └── user.json
    │
    ├── input/
    │   └── prompt.js
    │
    └── userMenu/
        ├── menu.js
        └── user.js

```

## Project Goals

The main purpose of this project is to build a strong practical understanding of:

 - JSON structure and data
 - Reading JSON files
 - Working with Node.js modules
 - Handling user input from the CLI
 - Creating interactive menus
 - Separating application logic into files
 - Organizing a Node.js project properly
 - Writing documentation for each learning task

# Learning Approach

Each task follows a simple workflow:

```
Learn
  ↓
Build
  ↓
Test
  ↓
Document
  ↓
Commit
  ↓
Move to Next Task
```

This approach keeps the project organized and makes it easy to review previous concepts.
